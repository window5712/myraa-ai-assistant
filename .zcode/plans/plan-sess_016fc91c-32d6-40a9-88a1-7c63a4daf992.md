## Myraa AI v2 — Electron Desktop Shell

### Goal
Wrap the existing web app into a real Windows desktop application (`Myraa AI v2`), with a **frameless window + custom title bar** and a **system tray + always-on-top toggle**. Reuse 100% of the existing server/client — **zero changes to `server.ts`, `App.tsx`, or `audio.ts` logic**.

### Key architecture insight (why this is low-risk)
Everything (HTTP + REST `/api/*` + WebSocket `/live` + static assets) already runs on **one port-3000 server**, and the client uses **only relative URLs** (`window.location.host` for WS, `/api/*` for REST). So the Electron window simply loads `http://localhost:3000` and the entire app works unchanged.

---

### Files to CREATE (new)

**1. `electron/main.cjs`** — Electron main process (CommonJS)
- On `app.whenReady()`: spawn the bundled server as a **child process** (`dist/server.cjs`), OR in dev run `tsx server.ts`. Wait for port 3000 to respond, then create the `BrowserWindow`.
- Window config: `frame: false`, `transparent: false`, `titleBarStyle: none`, `minWidth`/`minHeight`, dark background `#020205`, rounded corners on Win11.
- Loads `http://localhost:3000`.
- **Tray icon** (`electron/tray-icon.png`) with context menu: Show, Toggle Always-on-top, Quit. Close button → hide to tray (stay alive). Quit from tray → kill server + quit.
- **IPC handlers** for window controls: `window:minimize`, `window:maximize-toggle`, `window:close`, `window:toggle-pin` (always-on-top).
- Preload script for secure `window.electronAPI` bridge.
- On `before-quit`: kill the child server process.

**2. `electron/preload.cjs`** — secure context bridge
- Exposes a minimal, safe `window.electronAPI`: `minimize()`, `toggleMaximize()`, `close()`, `togglePin()`, plus an `onWindowMaximized(cb)` listener for UI sync.
- No Node integration, `contextIsolation: true`.

**3. `electron/tray-icon.png`** — a small icon (I'll generate a simple 16x16/32x32).

---

### Files to MODIFY

**4. `src/App.tsx`** — add window-control buttons into the existing header
- The header (line 484) already has `justify-between`. Add a **draggable region** (`-webkit-app-region: drag` on the header) and a small control cluster on the far right: Pin (always-on-top toggle), Minimize, Maximize, Close — only rendered when `window.electronAPI` exists (web mode is unaffected).
- New helper: `const isElectron = typeof window !== "undefined" && (window as any).electronAPI`.
- Buttons call `electronAPI.minimize()` etc. Non-draggable buttons get `-webkit-app-region: no-drag`.

**5. `package.json`** — add Electron wiring
- New devDeps: `electron`, `electron-builder` (or `concurrently` for dev).
- New scripts:
  - `electron:dev` → `concurrently "npm run dev" "wait-on http://localhost:3000 && electron ."`
  - `electron:build` → runs existing `build`, then `electron-builder` to produce a Windows installer (`nsis` `.exe`) in `release/`.
- New `"build"` field for electron-builder config (appId, productName `Myraa AI v2`, win target `nsis`, include `dist/` + `electron/`).
- New `"main": "electron/main.cjs"` entry point.

**6. `tsconfig.json`** — exclude `electron/*.cjs` from the TS type-check program (they're plain CJS, no need to type-check).

---

### What I will explicitly NOT do (scope guard)
- No new AI agents (File/System/Browser agents) — that's future work.
- No native Windows API control (volume/brightness/process-kill) — requires more IPC + native modules; out of scope for the shell.
- No auto-update server setup — I'll add the electron-updater *hook* structure but not a real update feed.
This is the **shell only**: a real, runnable `.exe` window that contains the existing Myraa, plus tray + pin.

---

### Verification plan
1. `npx tsc --noEmit` → 0 errors (electron files excluded).
2. `npm run build` → produces `dist/` + `dist/server.cjs` (existing pipeline, unbroken).
3. `npm run electron:dev` → launches the desktop window pointing at the running server; avatar videos + voice + memory all work.
4. Test: minimize/maximize/close-to-tray, tray show/quit, always-on-top toggle.
5. `npm run electron:build` → produces `release/Myraa AI v2 Setup x.y.z.exe`.

### Risks / notes
- The server is spawned as a **child process** — a console window may flash on Windows; I'll use `windowsHide: true` and detached handling to suppress it.
- `mic`/`getDisplayMedia` already work in Electron with the right permissions; `getDisplayMedia` for screen-share needs a `session.setDisplayMediaRequestHandler` in main — I'll add that so "Share Screen" keeps working in the desktop app.
- `contextIsolation: true` + preload is the secure modern pattern; I'll avoid `nodeIntegration` entirely.
